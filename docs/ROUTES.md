# 읽는 길: 시기와 테마

사용자가 고르는 읽는 길은 네 가지입니다. 전체 순서(원래 3650일), 시기별, 테마별, 갈래별입니다. 길을 고르면 오늘의 말씀이 그 길 안에서 하루에 하나씩 순서대로 나옵니다.
이 문서는 시기와 테마를 `data/plan.json`에 붙이고 고치는 사람을 위한 것입니다.

## 어디에 저장되나
- 날마다 `era`(시기 id 하나)와 `themes`(테마 id 한두 개)가 `title` 바로 뒤에 들어 있습니다.
- 시기와 테마의 이름과 설명은 파일 머리말의 `routes`에 있습니다(`routes.era`, `routes.theme`). 위젯은 이 정의를 읽어서 길 목록을 만듭니다. 정의에 없는 id는 길이 되지 않고, 날이 하나도 없는 길은 목록에서 빠집니다.
- 갈래별은 날마다의 `section` 값을 그대로 씁니다.
- 각 길 안의 순서는 원래 3650일의 순서입니다.
- 시기와 테마가 없는 옛 계획표도 돌아가며, 이때는 전체 순서와 갈래별만 보입니다.

`tools/routes.py`가 정의(`ERAS`, `THEMES`)와 시기 규칙표를 갖고 있고, `tests/test_routes.py`가 `plan.json`이 이 정의와 맞는지 확인합니다.

```
python tools/routes.py --check          정의와 plan.json 이 맞는지, 시기와 테마마다 날 수가 알맞은지 점검
python tools/routes.py --summary        시기와 테마마다 며칠인지
python tools/routes.py --stamp-eras     규칙표대로 날마다 era 를 다시 쓰고 머리말의 routes 를 갱신
python tools/routes.py --stamp-themes F F(JSON {"일차": ["테마 id", ...]})대로 날마다 themes 를 씀
```

## 시기
책 이름으로 나눈 읽기 길잡이입니다. 책을 쓴 때를 학자마다 다르게 보는 책이 있어서(요엘, 오바댜, 욥기 등) 연대를 따지려는 것이 아니라 읽기 편하게 묶은 것입니다. 연대를 적지 않습니다.

| id | 이름 | 책 |
|---|---|---|
| beginnings | 창조와 족장 | 창세기 |
| exodus | 출애굽과 광야 | 출애굽기, 레위기, 민수기, 신명기 |
| settling | 정착과 사사 | 여호수아, 사사기, 룻기 |
| kingdom | 다윗과 솔로몬 | 사무엘상하, 역대상, 열왕기상 1~11장, 역대하 1~9장 |
| prophets | 갈라진 나라와 선지자 | 열왕기상 12~22장, 열왕기하, 역대하 10~36장, 이사야, 호세아, 요엘, 아모스, 요나, 미가, 나훔, 하박국, 스바냐 |
| exile | 포로와 귀환 | 예레미야, 예레미야애가, 에스겔, 다니엘, 에스라, 느헤미야, 에스더, 학개, 스가랴, 말라기, 오바댜 |
| jesus | 예수님의 생애 | 마태복음, 마가복음, 누가복음, 요한복음 |
| church | 초대 교회 | 사도행전, 로마서부터 유다서까지 |
| revelation | 마지막 날의 환상 | 요한계시록 |
| timeless | 시대를 넘는 노래와 지혜 | 시편, 욥기, 잠언, 전도서, 아가 |

새 책을 계획표에 넣으면 규칙표(`BOOK_ERA`)에 없다는 오류가 나므로 거기에 더합니다.

## 테마
날마다 본문과 해설을 읽고 **어떤 마음으로 읽을 말씀인지**를 한두 개 붙입니다. 가장 중심인 것을 먼저 씁니다. 두 테마가 같은 무게일 때만 둘을 씁니다. 이 분류는 AI가 했고 사람이 검토하지 않았습니다.

| id | 이름 | 이런 날 읽을 말씀 |
|---|---|---|
| comfort | 위로와 쉼 | 지치고 마음이 무거운 날. 돌보심, 쉼, 품어 주심이 중심 |
| fear | 두려움과 불안 | 겁이 나고 앞이 막막한 날. 두려워하지 말라, 지켜 주심, 피난처가 중심 |
| thanks | 감사와 찬양 | 고마움을 말하고 싶은 날. 감사, 찬양, 기쁨, 노래가 중심 |
| repent | 회개와 용서 | 잘못을 돌아보고 새로 시작하고 싶은 날. 죄를 고백함, 용서, 돌아섬이 중심 |
| love | 사랑과 이웃 | 가까운 사람과 낯선 이웃, 사랑 자체를 생각하는 날. 사랑, 긍휼, 섬김, 원수 사랑이 중심 |
| wisdom | 지혜와 일상 | 일, 돈, 말, 선택 같은 날마다의 문제. 지혜, 분별, 삶의 태도가 중심 |
| suffering | 고난과 견딤 | 아프고 억울하고 오래 기다리는 날. 고난, 인내, 의문, 슬픔이 중심 |
| prayer | 기도와 부르짖음 | 하나님께 솔직하게 말하고 싶은 날. 기도하는 사람, 탄원, 간구가 중심 |
| hope | 소망과 회복 | 무너진 자리에서 다시 일어서는 이야기. 약속, 회복, 새 일, 끝내 이루심이 중심 |
| justice | 공의와 정의 | 약한 사람 편에 서시는 하나님과 우리의 몫. 불의 고발, 가난한 이, 재판, 공정이 중심 |
| faith | 믿음과 순종 | 믿고 따라 나서는 결단. 부르심, 순종, 시험, 믿음의 선택이 중심 |
| god | 하나님을 알아 가기 | 하나님이 어떤 분인지 알고 싶은 날. 창조, 거룩, 다스리심, 성품, 이름이 중심 |
| community | 공동체와 가정 | 교회, 가정, 관계 속에서 사는 법. 함께 사는 일, 질서, 화해, 모임이 중심 |

비슷해 보이는 테마를 가르는 기준입니다.
- `comfort`와 `hope`: 지금 지친 마음을 안아 주는 말씀이면 comfort, 앞으로 올 회복과 약속을 말하면 hope.
- `fear`와 `faith`: 두려움을 달래는 말씀이면 fear, 결단하고 따라나서는 말씀이면 faith.
- `suffering`과 `comfort`: 고난 자체와 견딤, 의문이 중심이면 suffering, 위로가 중심이면 comfort.
- `wisdom`과 `god`: 사람이 어떻게 살지가 중심이면 wisdom, 하나님이 누구신지가 중심이면 god.
- `love`와 `community`: 이웃과 원수를 위한 사랑과 섬김은 love, 교회와 가정의 질서와 함께 사는 법은 community.
- `repent`와 `justice`: 내 죄를 돌아보는 쪽이면 repent, 사회의 불의를 고발하는 쪽이면 justice.

붙일 때의 원칙입니다.
- 제목이나 갈래만 보고 붙이지 않습니다. 본문과 해설을 모두 읽습니다. 시편이라고 모두 기도나 감사로 붙이지 않고 시마다 실제 내용을 봅니다.
- 스치듯 한 번 나오는 낱말로 붙이지 않습니다. 그 테마를 골라 읽은 사람이 읽길 잘했다고 느낄 만해야 합니다.
- 한 테마로 쏠리지 않게 합니다. 점검은 테마마다 35일 이상 400일 이하를 요구합니다.
- 테마 이름과 설명도 해설과 같은 문체 규칙(번역투 금지)을 지킵니다. `tests/test_style.py`가 `ERAS`와 `THEMES`의 이름과 설명을 점검합니다.

## 길을 더하거나 바꾸려면
1. `tools/routes.py`의 `ERAS` 또는 `THEMES`에 `{id, name, about}`를 더합니다. id는 영문 소문자입니다.
2. 시기는 규칙표(`BOOK_ERA`, 장으로 가르는 책은 `SPLIT_BOOKS`)를 고치고 `--stamp-eras`를 돌립니다. 테마는 날마다 분류한 JSON으로 `--stamp-themes`를 돌립니다.
3. `--check`와 `python -X utf8 -m unittest tests.test_routes tests.test_style`로 확인하고, 버전을 올려 릴리스합니다([RELEASING.md](RELEASING.md)). 길 정의가 바뀌어도 `kyeon.py`는 고칠 필요가 없습니다. 사용자가 이미 고른 길의 id가 사라지면 위젯은 전체 순서로 돌아갑니다.
