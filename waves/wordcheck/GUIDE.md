# 낱말 점검 지침

장면 후보의 필수어(낱말)가 **한국어 문장에 그 글자 그대로(띄어쓰기 없이) 한 낱말로 자연스럽게 들어갈 수 있는지** 가려냅니다. 해설 작가가 이 낱말을 오늘 단락 첫 두 문장에 그대로 써야 하기 때문입니다.

## 부적합한 낱말(골라낼 것)
- 관형어나 동사 활용형이 붙은 구를 띄어쓰기 없이 붙여 놓은 것: 갈라진벽, 구운떡, 갚을돈, 구르는소리, 가파른길, 구멍난양말, 그을린창
- 평소에 띄어 쓰는 명사구를 붙여 만든 말: 공책한권, 쥐는힘, 가슴오르내림, 갱신안내, 굽높은구두
- 사전에도 생활 글에도 없는 즉석 합성어, 말이 되지 않는 말: 식힘판, 경품함처럼 어색한 것
- 뜻이 모호한 줄임말이나 조사가 붙은 형태: 결로(결에 로), 과로가 아닌 꼴로 조사처럼 보이는 것은 제외하지 않습니다(과로는 실제 낱말이라 통과)
- 장면 이름과 어울리지 않는 말은 보지 않습니다. 낱말 자체만 봅니다.

## 통과시킬 낱말(골라내지 말 것)
- 사전에 있거나 신문, 생활 글, 전문 분야에서 한 낱말로 굳은 말: 가계도, 결석생, 군화, 굵은소금, 검은깨, 감자캐기, 공차기, 고기굽기, 구멍뚫기(작업 이름), 경품권, 계량기
- 동사에서 나온 명사(캐기, 굽기, 차기), 접미사가 붙은 명사(결석생, 공시생)
- 확신이 서지 않으면 통과시킵니다(꼭 어색한 것만 골라내세요).

## 일
`wordcheck/words_<a|b>.json`(낱말 목록, JSON 배열)을 읽고, 부적합한 낱말만 모아 `wordcheck/bad_<a|b>.json`(JSON 배열, 낱말 문자열)에 **Write 도구**로 저장합니다. 마지막 보고에 전체 개수와 골라낸 개수를 한 줄로 적습니다.
