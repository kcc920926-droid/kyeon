# 켠 (kyeon)

> **화면 한켠, 마음 한가운데**

**켠**은 화면 한켠에 조용히 앉아 있다가, 하루에 한 번 말씀 한 덩이를 보여 주는 Windows 위젯입니다.
본문은 개역한글이고, 그 아래에 이 말씀이 그 시대에는 어떤 뜻이었는지, 오늘 내 하루에는 어떻게 닿는지를 짧게 붙였습니다.

이름에는 뜻이 둘 있습니다. 화면의 **한켠**에 자리 잡는다는 뜻과, 컴퓨터를 **켤** 때마다 불이 하나 들어온다는 뜻입니다.
성경을 통 읽지 못한 요즘, 하루에 한 덩이만 마음 한가운데에 놓아 보자는 데서 시작했습니다.

## 특징

- **조용합니다.** 평소에는 보이지 않다가 로그온할 때와 매일 자정에 오른쪽 아래에 뜹니다. 읽고 `오늘은 닫기`를 누르면 그날은 다시 뜨지 않습니다.
- **1000일치입니다.** 시편 225일, 복음서 225일, 그 밖의 성경 550일로 66권 전체를 지납니다. 시편과 복음서가 번갈아 나오고 그 사이에 다른 책이 끼어듭니다. 복음서는 예수님의 생애 순서로 읽고, 다른 복음서에 같은 사건이 있으면 병행 본문을 표시합니다.
- **해설이 당시의 뜻에서 시작합니다.** 풍습, 지리, 제도, 낱말의 쓰임을 먼저 짚고 오늘의 장면으로 잇습니다. 형식은 6가지이고 본문의 성격에 맞춰 돌아가며 나옵니다.
- **암송 모드가 있습니다.** 스위치를 켜면 단계에 따라 낱말이 띠로 가려지고, 누르면 보입니다.
- **업무 중에도 화면 한켠에 둘 수 있습니다.** 엑셀 스타일로 바꾸면 위젯이 스프레드시트처럼 보입니다. 구절은 행으로, 번호는 A열로 놓입니다.
- **설정 창에서 바꿉니다.** 화면 스타일, 테마, 글자 크기, 표시 위치, 암송, 읽기 진행, 자동 실행을 누르는 즉시 적용합니다.
- **가볍습니다.** 파이썬 표준 라이브러리(tkinter)만 씁니다. 추가 설치도, 인터넷도, 관리자 권한도 필요 없습니다.

## 설치

필요한 것: Windows 10/11, Python 3.8 이상(tkinter 포함. python.org 설치본이면 됩니다)

1. 저장소를 내려받아(`Code > Download ZIP`) 원하는 폴더에 풉니다.
2. `install.bat`을 실행합니다. 로그온 시 자동 실행을 등록하고 지금 바로 위젯을 띄웁니다.
   특정 Python을 쓰려면 `install.bat C:\Python313\python.exe`처럼 경로를 줍니다.
3. 지우려면 `uninstall.bat`을 실행합니다.

자동 실행은 레지스트리 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`에 `Kyeon` 값 하나만 만듭니다. 폴더나 Python을 옮겼다면 `install.bat`을 다시 실행하세요.

## 쓰는 법

- 위젯 윗부분을 끌어 위치를 옮깁니다. 본문이 길면 마우스 휠로 넘깁니다. 윈도우의 라이트/다크 테마를 따라갑니다.
- 오늘 이미 닫았는데 다시 보고 싶으면 `show.bat`을 실행합니다.
- 시작한 날이 1일차입니다. 1000일을 다 읽으면 처음부터 다시 돕니다. 처음부터 다시 하려면 `python kyeon.py --reset`을 실행합니다.

### 설정 창

위젯 머리줄의 톱니(⚙)를 누르면 설정 창이 열립니다. 엑셀 스타일에서는 왼쪽 위 `파일` 메뉴도 같은 창을 엽니다. 바꾼 값은 바로 적용되고 저장됩니다.

| 항목 | 고를 수 있는 값 |
|---|---|
| 스타일 | 기본, 엑셀(업무용) |
| 테마 | 자동(윈도우 설정을 따름), 라이트, 다크. 엑셀 스타일은 밝은 화면으로 고정 |
| 글자 크기 | 작게, 보통, 크게 (위젯 폭도 함께 바뀝니다) |
| 표시 위치 | 왼쪽 위, 오른쪽 위, 왼쪽 아래, 오른쪽 아래 |
| 항상 위에 | 켬, 끔 |
| 암송 모드 | 켬, 끔, 가릴 단계 1·2·3 |
| 읽기 | 일차를 정해 이동, 처음부터 다시 |
| 시작 | 로그온할 때 자동 실행 켬, 끔 |

화면이 낮아 위젯이 한 번에 들어가지 않으면 글자를 한 단계 줄여서 맞춥니다.

### 엑셀 스타일

초록색 제목 줄, 메뉴 줄, 수식 입력줄, 열 머리글(A, B), 줄무늬 행, 시트 탭을 갖춘 화면입니다. 구절 번호는 A열, 본문은 B열에 놓이고 해설은 아래의 칸에 나옵니다. 설정 창에서 `엑셀`을 고르거나 `python kyeon.py --skin excel`로 바꿉니다. 메뉴 줄은 모양일 뿐이고 `파일`만 설정 창을 엽니다.

### 암송 모드

위젯 오른쪽 위의 `○ 암송`을 누르면 켜지고, 옆에 1·2·3 단계가 나타납니다. 켜고 끈 상태와 단계는 기억합니다.

| 단계 | 가리는 것 |
|---|---|
| 1 | 구절마다 그 구절을 대표하는 핵심 단어 1~3개 (태초, 가라지, 사랑처럼) |
| 2 | 1단계에 더해 명사, 동사, 형용사, 부사 등 뜻을 가진 낱말 전부. 조사와 어미는 남습니다 |
| 3 | 나머지 조사와 어미까지 모든 글자 |

가려진 곳은 글자 수만큼의 띠로 보입니다. 띠를 누르면 그 낱말이 보이고, 오른쪽 `다시 가리기`를 누르면 처음 상태로 돌아갑니다. 위젯이 다시 뜨면 항상 처음처럼 가려져 있습니다.

핵심 단어는 사람이 하나하나 고른 것이 아니라 계산한 결과입니다. 성경 전체에서 얼마나 드물게 나오는지, 그날 제목에 들어 있는지, 본문 안에서 되풀이되는지를 점수로 매겨 골랐습니다. 낱말을 나누는 일은 한국어 형태소 분석기 [Kiwi](https://github.com/bab2min/Kiwi)(kiwipiepy)가 맡았고 결과만 `data/plan.json`의 `lv`에 담았습니다. 옛 문체 탓에 어색하게 나뉘는 곳이 가끔 보입니다.

### 명령줄

```
python kyeon.py --status       등록과 진행 상태
python kyeon.py --check        데이터 점검 + 오늘의 말씀을 콘솔에 출력
python kyeon.py --day 100      100일차 미리보기 (진행 상태를 바꾸지 않음)
python kyeon.py --day 100 --recite 2   100일차를 암송 모드 2단계로 미리보기
python kyeon.py --day 100 --skin excel 100일차를 엑셀 스타일로 미리보기
python kyeon.py --skin excel   화면 스타일을 저장 (default 또는 excel)
python kyeon.py --settings     설정 창을 바로 열기 (떠 있는 위젯이 있으면 그 위젯에서 열림)
python kyeon.py --quit         실행 중인 위젯 종료
python kyeon.py --version
```

## 읽기 계획

| 구분 | 일수 | 내용 |
|---|---|---|
| 시편 | 225 | 시편 150편을 의미 단위로 나눔 |
| 복음서 | 225 | 예수님의 생애 순서, 병행 본문 표시 |
| 구약 이야기 | 242 | 창세기부터 에스더까지 |
| 지혜서·선지서 | 168 | 욥기부터 말라기까지 |
| 신약 | 140 | 사도행전, 서신서, 요한계시록 |

하루치는 의미가 끊기지 않는 덩어리입니다. 짧으면 한 편의 시, 길면 한 장면이나 한 단락입니다.

## 해설 형식

| 형식 | 흐름 |
|---|---|
| 그때·오늘 | 그 당시의 배경 → 오늘 |
| 흔한 오해 바로잡기 | 흔한 읽기 → 당시의 뜻 → 오늘 |
| 한 단어 풀이 | 본문 속 낱말 하나가 당시에 뜻하던 것 → 오늘 |
| 그 자리에 서 보기 | 그 자리에 있던 사람의 눈으로 본 장면 → 오늘 |
| 오늘의 기도로 | 그 당시의 배경 → 짧은 기도 |
| 큰 이야기 속 위치 | 성경 전체 줄거리 속에서 이 본문의 자리 → 오늘 |

마지막에는 그날을 위한 질문이 하나 붙습니다.

해설은 **AI가 본문을 보고 썼고 사람이 한 줄씩 검토하지는 않았습니다.** 역사와 언어는 널리 받아들여진 지식만 쓰고 학설이 갈리는 곳은 단정을 피하는 것이 원칙입니다. 쓴 사람이 사실이 불확실하다고 표시한 해설 166개는 성경 본문과 웹 자료로 한 번 더 확인했고 그중 51개는 틀린 설명을 고치거나 단정을 낮췄습니다. 이 확인도 AI가 한 것이므로 틀린 곳이 남아 있을 수 있습니다. 신학적으로 민감한 부분은 직접 확인해 주세요. 고치려면 `data/plan.json`의 `blocks`와 `question` 값을 바꾸면 바로 반영됩니다. 작성 규칙은 [docs/STYLE.md](docs/STYLE.md)에 있습니다.

글투는 [Bamti](https://github.com/kcc920926-droid/bamti)가 옮겨 쓴 [im-not-ai](https://github.com/epoko77-ai/im-not-ai)의 한국어 문체 규칙으로 점검했습니다. 연결어미 뒤 쉼표, 같은 끝맺음의 연속, 부풀린 의의 표현, 진부한 비유 같은 AI 투를 걸러 냈고, 문장 시작과 질문 끝맺음이 한쪽으로 쏠리지 않게 전체 분포도 확인했습니다.

## 본문 출처

- 본문은 위키문헌 [개역한글판](https://ko.wikisource.org/wiki/개역한글판)에서 가져왔습니다. 위키문헌은 이 판을 저작권이 만료된 것(2012년)으로 분류하고 있으나, 대한성서공회가 직접 확인해 준 것은 아닙니다. 널리 배포하기 전에 확인하세요.
- 가져온 판본에서 아래를 정리했습니다.
  - 위키문헌 판은 `세례`를 `침례`로 바꿔 놓은 곳이 많아, 이 계획에 들어간 절은 대한성서공회 개역한글의 표기인 `세례`로 되돌렸습니다. 되돌린 절의 수는 `data/plan.json`의 `source`에 적혀 있습니다.
  - 사본에 없는 절 표시(`[없음]`)는 화면에서 뺐고, 짝이 맞지 않는 괄호를 정리했습니다.
  - 시편 표제(`다윗의 시` 등)는 본문과 떼어 작은 글씨로 보여 줍니다.
  - 시편 83:6의 `이스라엘 인`은 위키문헌의 입력 오류로 보여 `이스마엘 인`으로 고쳤습니다. 같은 절에 나오는 에돔, 모압, 하갈 사람의 짝이 되는 이름입니다.
  - `(앞절과 동일)`, `(2절과 상동)`처럼 절이 합쳐져 인쇄된 곳은 개역한글 인쇄본의 표기라서 그대로 두었고, 암송 모드에서도 가리지 않습니다(6곳).
- 그 밖의 글자는 위키문헌 원본 그대로여서 인쇄본과 한두 글자 다를 수 있습니다.
- 개역한글에는 오늘 쓰지 않는 표현(문둥병, 소경 등)이 있습니다. 본문은 그대로 두었고 해설에서는 오늘의 표현을 썼습니다.

## 폴더 구조

```
kyeon.py            위젯 본체 (표준 라이브러리만 사용)
data/plan.json      1000일치 본문, 해설, 질문, 암송용 가림 정보
install.bat         자동 실행 등록 + 지금 실행
uninstall.bat       자동 실행 해제
show.bat            위젯 다시 띄우기
docs/STYLE.md       해설 작성 규칙
tests/              단위 테스트
```

`plan.json`의 하루치 모양은 아래와 같습니다.

```json
{
  "day": 3, "section": "복음서", "ref": "요한복음 1:1–14", "title": "태초부터 계신 말씀",
  "parallels": [],
  "verses": [[1, 1, "태초에 말씀이 계시니라 ..."]],
  "format": 1,
  "blocks": [{"label": "그 당시", "text": "..."}, {"label": "오늘", "text": "..."}],
  "question": "...?",
  "lv": ["2230232 ..."]
}
```

`lv`는 구절마다 본문과 같은 길이의 숫자열입니다. 0은 가리지 않는 글자(공백, 문장부호), 1은 핵심 단어, 2는 그 밖의 내용어, 3은 나머지입니다.

## 개발

```
python -X utf8 -m unittest discover -s tests -v
```

Windows와 tkinter가 필요합니다. 테스트가 1000일 전체를 한 번씩 그려 보고 위젯이 화면 안에 들어가는지도 확인하기 때문에 2분쯤 걸립니다.
